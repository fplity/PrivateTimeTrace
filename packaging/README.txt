Windows x64 local study timer. No account or cross-device sync.
项目主页：https://github.com/fplity/PrivateTimeTrace

完整解压文件夹后运行 PrivateTimeTrace.exe；不要只复制一个 exe。
已包含 .NET 与 Windows App SDK 运行组件，不需要开发者模式。

使用前请阅读 LICENSE、THIRD_PARTY_NOTICES.md 和 licenses/ 内的原始条款。

右上角切换霜白玻璃 / 液态流光；两个图表各自切换折线 / 柱状。
输入主题并开始专注；关闭窗口会保留活动计时，结束并保存才结束记录。

数据目录：%LOCALAPPDATA%\PrivateTimeTrace\
备份前关闭全部应用窗口，再复制完整数据目录。数据未进行应用级加密。
