# 双主题与图表切换实施记录

范围：Windows 原生 C# / .NET 10 / WinUI 3 / MVVM / SQLite；本地单机。

用户批准同时保留两版设计，可随时切换。默认使用液态流光，另一版为霜白玻璃。

- 霜白玻璃：轻柔冰蓝底色、较高磨砂度、弱阴影。
- 液态流光：银蓝与暖白环境光、通透边缘、层级阴影、指针高光、按压过渡。
- 专注趋势、主题分布分别保存折线 / 柱状图偏好，切换互不影响。
- 主题、图表偏好写入原 SQLite 新增的 app_settings 表；历史数据继续使用原表。
- 保留参考图于 docs/design/，实现使用独立背景素材和真正的原生交互控件。
- 启动、结束计时、主题切换、图表切换、重启恢复、空状态、窗口缩放均需实际检查。
- 统计卡片与图表采用同样的时间区间裁剪规则；跨午夜学习不会整段重复计入两天。
- 验证使用独立数据库，真实数据库不写入演示记录。

本轮遵循用户禁止默认委托智能体的要求，由主会话实施与验证，不能称为独立测试员验收。

## 设计素材

背景由 imagegen 生成并保存为 `Assets/LiquidBackdrop.png`：无文字的珍珠银蓝空间、透明弧形玻璃带、左上方暖白环境光、右下方较深的蓝灰层次。生成素材仅用于环境底图；可读内容、折线与柱形、导航、计时及交互均由 WinUI 原生绘制。

最终实施及实际窗口验证结果见 `docs/verification-report.md`。
