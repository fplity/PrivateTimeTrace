# 时间迹 1.0.0 · 首个 Windows 安装版

记录每一次专注，用清晰的图表回顾自己的投入。

## 下载

- **普通用户**：下载 `PrivateTimeTrace-1.0.0-win-x64-Setup.exe`，双击安装。
- **免安装**：下载 `PrivateTimeTrace-1.0.0-win-x64.zip`，完整解压后运行 `PrivateTimeTrace.exe`。
- `SHA256SUMS.txt` 提供下载一致性校验。GitHub 自动生成的 Source code 压缩包是源码，不是可运行程序。

推荐 Windows 11 x64。安装包包含 .NET / WinUI 运行组件，无需开发者模式或额外开发环境。安装面向当前用户，卸载保留学习数据。

## 这一版包含

- 原生学习计时、活动计时恢复、历史记录、主题查看与删除确认。
- 霜白玻璃 / 液态流光两种风格随时切换，新设计的玻璃计时环图标。
- 专注趋势、主题分布各自支持折线 / 柱状切换，独立保存偏好。
- 日 / 周 / 月 / 年 / 全部范围，跨午夜统计按实际时间分配。
- SQLite 本地存储，无账号、云同步或应用自己的学习数据上传。

项目采用 C# + .NET 10 + WinUI 3 + MVVM + SQLite。原创代码采用 MIT；完整微软运行库条款、第三方许可与隐私说明均随包提供。

## 验证与注意事项

已完成 21 项核心检查，以及实际安装后的 UI、计时恢复、8 种显示组合、覆盖升级和保留数据的卸载验证。详见仓库的 `docs/release-verification.md`。

**当前安装包未使用商业代码签名证书**，Windows 可能显示未知发布者。请核对本仓库来源与 SHA-256，不要关闭系统安全防护或导入陌生证书。SHA-256 不能代替独立的发布者身份认证。

数据目录为 `%LOCALAPPDATA%\PrivateTimeTrace\`，未进行应用级加密。重要数据请在关闭全部应用窗口后备份整个数据目录。当前仅验证本机 Windows x64，未覆盖全部系统 / 显卡组合；无自动更新器和双端同步。
