# 时间迹使用手册

本手册对应 v1.1.1 的已实现功能。项目首页见 [README](../README.md)，下载入口见 [最新 Release](https://github.com/fplity/PrivateTimeTrace/releases/latest)。

## 安装与第一次启动

### 使用安装器

1. 从 Release 下载 `PrivateTimeTrace-1.1.1-win-x64-Setup.exe`。
2. 如需检查文件一致性，下载 `SHA256SUMS.txt`，使用 PowerShell 的 `Get-FileHash -Algorithm SHA256` 比较对应文件的哈希。
3. 运行安装器，阅读应用及随包组件的许可，选择是否建立桌面快捷方式，完成安装。
4. 从开始菜单或桌面打开「时间迹」。

程序安装在当前用户的 `%LOCALAPPDATA%\Programs\PrivateTimeTrace`，数据存放在独立的 `%LOCALAPPDATA%\PrivateTimeTrace`。普通安装不需要管理员权限、开发者模式或额外 .NET 开发环境。

当前发行安装器没有 Authenticode 签名，可能出现未知发布者提示。请确认文件来自本项目 Release；不要因安装而关闭系统安全防护。组织管理的电脑若限制未签名软件，需要按组织要求处理。

### 使用免安装 ZIP

1. 下载 `PrivateTimeTrace-1.1.1-win-x64.zip`。
2. 将压缩包完整解压到一个可访问的文件夹。
3. 保留其中所有 DLL、资源和运行组件，打开 `PrivateTimeTrace.exe`。

ZIP 版的默认数据位置与安装版相同。移动 ZIP 程序文件夹不会一并移动学习数据；将程序复制到另一台电脑，也不会自动带走记录。`Source code` 压缩包用于开发，不包含已经构建好的应用。

### 首次界面

应用进入「概览」。首次运行默认选择液态流光风格、周统计、趋势折线图和主题柱状图。没有已完成记录时，图表显示引导信息；这时可以直接开始第一次学习。

## 三个页面

| 页面 | 用途 | 主要内容 |
| --- | --- | --- |
| 概览 | 开始和结束学习，快速回顾投入 | 计时器、主题输入、今日／本周累计、周期图表、最近 3 条记录 |
| 学习记录 | 查看现存历史，处理单条记录 | 主题、开始时间、完整时长、删除操作 |
| 数据分析 | 比较时间趋势与学习方向 | 五种统计范围、两张图表、主题明细及下钻入口 |

右上角风格入口在页面滚动时仍可使用。窗口变窄后导航会压缩，两张图表可改为上下排列；可用空间不足时通过页面滚动访问下方内容。

## 记录一次学习

### 开始

在「概览」填写主题，例如「英语阅读」，点击「开始专注」。主题最长 120 个字符，可以留空；空主题在记录中显示为「未命名学习」。

开始成功后，按钮变为「结束并保存」，主题输入锁定，计时显示按秒更新。主题和开始时间写入本地数据库；当前只支持一次活动计时。

### 结束

完成学习后点击「结束并保存」。应用将活动计时转换为已完成记录，清空活动状态，刷新累计、图表和最近记录。保存成功后可以填写新主题并开始下一次学习。

统计只使用已完成记录。正在进行的计时不会逐秒增加「今日累计」「本周累计」或图表数值，结束保存后才会进入统计。

### 关闭、睡眠与恢复

关闭窗口不会自动结束或暂停学习。再次启动时，应用读取原来的开始时间，并按其到当前系统时间的间隔显示时长；关闭窗口、电脑睡眠及离开电脑的间隔都会包含在内。

当前没有暂停、空闲检测或自动扣除休息时间的功能。准备离开学习时，请先结束并保存。尚未开始计时的输入内容不属于已保存的学习记录。

### 系统时间与保存失败

计时依据系统时间计算。如果系统时间被调整，经过时长可能受到影响。若结束时间早于开始时间，应用拒绝保存，并保留活动计时，提示校准时间后重试。

出现保存错误时，先查看页面提示，确认数据目录可访问、磁盘空间足够，必要时备份数据后再排查。不要通过删除数据库来尝试修复单次保存错误。

## 查看与删除记录

「学习记录」默认显示现存全部已完成记录，按开始时间倒序排列。每条记录显示主题、开始日期／时间和完整时长。

从「主题分布」的数据标记或「主题明细」进入时，会显示该主题在当前分析周期内的记录。返回侧边导航的「学习记录」可查看全部记录；重新进入普通页面会清除主题筛选。

删除操作会先显示确认对话框。确认删除后，对应记录从数据库中移除，累计时长、趋势、主题分布和最近记录更新。当前没有回收站或撤销按钮，重要数据请先备份。

## 阅读图表

### 周期切换

| 选择 | 范围 | 趋势分桶 |
| --- | --- | --- |
| 日 | 今天 | 每小时，共 24 个点 |
| 周 | 本周，周一至周日 | 每天，共 7 个点 |
| 月 | 本月 | 每天，共 28–31 个点 |
| 年 | 今年 | 每月，共 12 个点 |
| 全部 | 现存全部已完成记录 | 按涉及的月份连续展示 |

日期按当前本地日期确定。当前没有前后周期选择或自定义日期区间；「全部」可以看到跨年的累计记录。每次启动的默认周期是「周」，风格和图表类型则恢复已保存的偏好。

### 专注趋势

横轴是时间，纵轴是对应时间段内累计的学习时长。纵轴根据量级以分钟 `m` 或小时 `h` 展示。

折线图适合观察投入的变化，柱状图适合比较各时间段的时长。没有记录的时间段保留零值；零时长的柱子没有高度，折线的数据点位于零轴。鼠标停在数据点、柱子或已显示的横轴标签上，可查看具体的时长提示。

v1.1.1 的日／月图完整显示整个时间范围；为避免文字拥挤，部分横轴数字会省略，但对应的数据点仍然存在。长期历史超过 31 个时间点时可横向滚动。

### 主题分布

横轴是主题名称，纵轴是主题在所选周期内的累计时长。主题按累计时长从高到低排列，同等时长时再按名称排序。超过 12 个主题时可横向浏览。

两张图表的类型分别控制。例如趋势使用柱状图时，主题图仍可使用折线图。主题折线连接的是不同主题的累计值，不能解释为时间序列或主题学习顺序。

点击主题数据点、柱子或下方的主题明细，可以进入对应记录列表。主题按去除首尾空白后的名称合并；「Java」和「Java 核心」会分别统计，空主题合并为「未命名学习」。

### 跨午夜记录为什么会分到两天

例如一条学习记录开始于 23:50，结束于次日 00:20：

| 查看方式 | 时长 |
| --- | --- |
| 原始记录 | 完整 30 分钟 |
| 开始当天的统计 | 当天重叠的 10 分钟 |
| 结束当天的统计 | 当天重叠的 20 分钟 |

趋势和主题累计采用相同的时间分配规则。某周期内显示的次数，是与该周期有重叠的记录数；一条跨午夜记录可能同时计入两天的次数，因此各日次数不一定能直接相加。

## 切换外观

右上角可切换「霜白玻璃」与「液态流光」。前者较柔和，后者的通透边缘与空间光影更明显。选择自动保存，下次启动恢复。

按钮内的玻璃选择胶囊在切换时滑动、轻微形变与回弹；局部高光跟随鼠标。系统减少动画或关闭高级视觉效果时，效果会降低。这些设置控制视觉表现，不改变学习记录和统计值。

## 备份与恢复

### 找到数据目录

按 `Win + R`，输入下面的目录路径并回车：

```text
%LOCALAPPDATA%\PrivateTimeTrace
```

这是文件夹入口。`private-time-trace.db` 及备份中的 `.db` 都是数据库文件，不是应用程序，日常无需双击它们。

### 备份

1. 如不希望计时继续，先结束并保存正在进行的学习。
2. 关闭所有时间迹窗口，包括安装版、ZIP 版和开发版。
3. 将整个专用数据目录复制到自己的备份位置。
4. 若存在 `private-time-trace.db-wal`、`private-time-trace.db-shm` 等 SQLite 辅助文件，一同保留，勿单独删除。
5. 为备份标明日期和应用版本，保留在自己可控的位置。

备份包含学习主题、时间记录、活动计时和显示偏好。若备份时有活动计时，将来恢复后仍会从保存的开始时间计算，因此通常先结束本次学习更容易管理。

应用没有自动备份任务或应用级数据库加密。若备份文件使用了 Windows EFS 等系统级加密，跨电脑恢复还需要相应的解密能力；仅复制文件不保证另一台电脑可以读取。

### 恢复到原机或另一台电脑

1. 安装匹配的应用版本，确认目标数据目录位置。
2. 关闭全部时间迹窗口。
3. **先备份目标电脑当前的数据目录**，避免替换后失去新记录。
4. 将待恢复的完整备份放到默认数据位置，保持数据库与辅助文件来自同一次备份。
5. 打开时间迹，检查记录、统计、显示偏好与活动计时是否符合预期。

恢复是替换，不是合并。不要将不同备份中的数据库和辅助文件混在一起，也不要在应用运行时覆盖数据库。当前没有多设备增量同步或两套数据自动合并工具。

## 更新与卸载

更新前备份数据并退出程序，再运行新版安装器。正在运行的应用会触发安装器占用保护；关闭窗口后重试。现有桌面快捷方式指向同一安装位置，更新后继续使用即可。

卸载通过 Windows「已安装的应用」或开始菜单卸载入口完成。卸载移除程序文件、专用快捷方式和卸载注册项，保留学习数据库，也保留安装目录中不属于本包的额外文件。

如果要完全清除个人学习数据，应先关闭应用、按需备份，再处理 `%LOCALAPPDATA%\PrivateTimeTrace` 这个专用目录。不要将整个 LocalAppData 当作清理目标。

## 问题排查

| 现象 | 先检查什么 |
| --- | --- |
| 正在计时但累计没有增加 | 是否已经点击「结束并保存」；活动计时尚未计入统计 |
| 某个周期没有图形 | 该周期是否有已完成记录；零记录会显示引导信息 |
| 日／月后半段记录看不到 | 是否仍在运行 v1.1.0 或更早版本；图表可见性修复在 v1.1.1 |
| 主题明细时长与列表时长不同 | 明细按当前周期裁剪，列表显示记录完整时长 |
| ZIP 版与安装版看到相同记录 | 二者默认共用当前 Windows 用户的数据目录 |
| 安装器提示程序占用 | 关闭全部时间迹窗口，再运行安装器 |
| 双击 EXE 无法启动 | ZIP 是否完整解压，组件是否被单独移动，是否为受支持的 x64 环境 |
| 恢复后记录不符合预期 | 是否恢复到了当前用户目录，是否误用另一套备份，活动计时是否仍在继续 |

启动失败时可以检查数据目录中的 `startup-error.log`（如已生成）。提交公开问题前请先检查截图和日志，去掉学习主题、用户名、个人路径及其他敏感内容。不要上传数据库。

反馈入口：[GitHub Issues](https://github.com/fplity/PrivateTimeTrace/issues)。请说明应用版本、Windows 版本、问题步骤、预期与实际结果；安全漏洞按 [安全说明](../SECURITY.md)报告。
